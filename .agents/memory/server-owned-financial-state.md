---
name: Server-owned financial state
description: قاعدة أن كل الرصيد والمكافآت والحجوزات والحالات القابلة للقيمة المالية تُحسم في معاملات Backend لا من المتصفح.
---

الرصيد، الرصيد المحجوز للسحب، الإيداعات المقبولة، السحوبات المنفذة، الإحالات، VIP، المهام، المكافآت اليومية، والعجلة يجب أن تتغير فقط داخل API موثقة ومعاملات PostgreSQL؛ بيانات الواجهة للعرض فقط.

**Why:** أي حالة مالية قابلة للكتابة من Frontend يمكن تزويرها حتى لو كانت الواجهة نفسها تخفي الأزرار.

**How to apply:** عند إضافة مكافأة أو شراء أو مهمة أو تدفق مالي جديد، أنشئ endpoint خادماً يتحقق من الجلسة والرصيد والحالة والتكرار، وسجّل الأثر في transactions داخل نفس المعاملة.
