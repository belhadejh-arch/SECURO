إعادة تصميم وهيكلة الواجهة بالكامل — Responsive احترافي
أريد منك عمل تغيير جذري في Layout والـResponsive Design للواجهة الحالية لأن الواجهة الحالية غير متناسقة، أجزاء من الشاشة تختفي، وهناك فراغات كبيرة، والتمرير لا يعمل بشكل مريح.
مهم جدًا: لا تعيد بناء المنصة من الصفر، ولا تغيّر Backend أو Database أو Authentication أو الوظائف. غيّر طبقة الواجهة والـLayout فقط مع الحفاظ على كل الوظائف الحالية.
1. نظام Layout جديد
أعد تنظيم الصفحة إلى:
Header → Main Content → Bottom Navigation
واجعل Main Content هو الجزء القابل للتمرير، وليس الصفحة كاملة بطريقة تسبب مشاكل.
لا تستخدم height: 100vh لتقييد المحتوى.
لا تستخدم overflow: hidden على الحاوية الرئيسية إذا كان يمنع الـScroll.
أزل أي position: absolute/fixed غير ضروري.
أزل أي margin/padding/spacer يسبب الفراغ الكبير في الأعلى.
اجعل ارتفاع المحتوى auto حسب محتواه الحقيقي.
2. الهاتف
صمم الواجهة أولًا للهاتف:
المحتوى يظهر كاملًا داخل عرض الشاشة.
لا يوجد Horizontal Scroll.
يمكن السحب للأعلى والأسفل بسهولة.
جميع الأقسام تظهر حتى آخر عنصر.
آخر عنصر لا يختفي خلف Bottom Navigation.
الأزرار والحقول مناسبة للمس.
لا يوجد قص أو تداخل.
3. الكمبيوتر والTablet
اجعل نفس الواجهة تتكيف تلقائيًا مع:
Mobile
Tablet
Desktop
بدون تمديد مبالغ فيه أو فراغات كبيرة.
4. الصفحة الرئيسية
بعد تسجيل الدخول:
يظهر Header بشكل صغير ومنظم.
يبدأ المحتوى مباشرة تحته.
لا يوجد فراغ كبير في الأعلى.
Cards مرتبة بمسافات متساوية.
عجلة الحظ والمكافآت والمهام وجميع الأقسام تظهر بالترتيب.
يمكن الوصول إلى آخر قسم بالسحب بسهولة.
5. Bottom Navigation
أعد تنظيم الـBottom Navigation:
يكون بحجم مناسب وليس مرتفعًا جدًا.
لا يغطي محتوى الصفحة.
يبقى ثابتًا إذا كان هذا هو التصميم الحالي.
أضف مساحة سفلية محسوبة للمحتوى فقط بقدر الحاجة.
6. جميع الصفحات
طبّق نفس نظام الـLayout على:
الصفحة الرئيسية
المهام
المكافآت
عجلة الحظ
الفريق/الإحالات
الملف الشخصي
الإيداع
السحب
الإعدادات
تسجيل الدخول
إنشاء الحساب
لوحة Admin
كل صفحة يجب أن تظهر بالكامل ويمكن الوصول إلى آخر محتوى فيها بالتمرير.
7. Admin Dashboard
اجعل لوحة Admin احترافية ومتجاوبة:
Cards منظمة.
الجداول لا تخرج من الشاشة.
على الهاتف يمكن تمرير الجداول أفقيًا عند الضرورة فقط.
الأزرار واضحة وسهلة الضغط.
لا يوجد محتوى مقصوص.
8. التنظيف النهائي
ابحث في المشروع عن CSS متعارض أو مكرر يسبب المشاكل، خصوصًا:
height: 100vh
min-height
overflow: hidden
position: fixed
position: absolute
margin-top
padding-top
max-height
أصلح التعارضات بدل إضافة CSS فوق CSS القديم.
ممنوع عمل حلول مؤقتة مثل إضافة Padding كبير فقط لإظهار المحتوى.
9. الاختبار الإجباري
بعد التنفيذ اختبر كل صفحة:
Mobile → Tablet → Desktop
واختبر:
الدخول.
فتح الصفحة الرئيسية.
السحب من الأعلى للأسفل.
الوصول إلى آخر عنصر.
فتح المهام.
فتح عجلة الحظ.
فتح الإيداع والسحب.
فتح الملف الشخصي.
لوحة Admin.
لا تعتبر المهمة مكتملة حتى تكون جميع الصفحات ظاهرة بالكامل، متناسقة، وقابلة للتمرير بسلاسة، وبدون فراغات كبيرة أو أجزاء مخفية.
نفّذ التعديلات فعليًا في ملفات المشروع، ولا تكتفِ بإعطائي شرحًا أو تقريرًا.
